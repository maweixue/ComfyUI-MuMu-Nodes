# MuMu 模型测试节点（私人插件）

一组私人开发的 ComfyUI 模型测试自定义节点，用于内部模型效果验证与画质对比测试。仅供测试使用。

## 安装

方法一：git clone（推荐）

```bash
cd ComfyUI/custom_nodes
git clone https://github.com/<用户名>/ComfyUI-MuMu-Nodes.git
```

重启 ComfyUI 后即可在节点列表中找到本插件。

方法二：ZIP 下载

下载本仓库 ZIP 压缩包，解压后将整个文件夹放入 `ComfyUI/custom_nodes/`，重启 ComfyUI。

## 节点列表

| 节点 | 类型 | 说明 |
|---|---|---|
| 木木2 / 木木3 | 文生图 | 模型测试（1K / 2K / 4K） |
| 木木2.1 / 木木3.1 | 图生图 | 模型测试（参考图 1~10） |
| 南南5 / 南南5.1 | 文生图 / 图生图 | 速度测试档（2K / 4K） |
| 木木4-备用 / 木木4.1-备用 | 文生图 / 图生图 | 备用测试档 |
| 木木5-备用 / 木木5.1-备用 | 文生图 / 图生图 | 备用测试档 |

## 使用说明

- 每个节点需在界面填写 API 密钥（密钥由插件作者提供，请勿外传）。
- 分辨率：`1K / 2K / 4K` 三档（南南5 系列仅提供 2K / 4K）。
- 宽高比：文生图提供 10 种常规比例；图生图额外提供「自动」——接入参考图后按参考图比例输出。
- 随机种子：默认随机；点击按钮可切换「固定 / 随机」。
- 图生图节点提供 10 个参考图输入口（图一 ~ 图十），按输入顺序参与生成。

## 说明

- 本插件为私人测试用途，参数与接口可能随时调整，请勿用于生产环境。
- 生成结果由上游接口提供，耗时受上游负载与网络影响，属于正常现象。
- 如遇「任务超时」「生成失败」等提示，请稍后重试或更换分辨率档位。
